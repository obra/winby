Features

Everything you need to
manage windows efficiently

Built for developers and power users who live in their keyboard.

🔍

Instant Search

Find any window by typing. Fuzzy search matches window titles and application names as you type.

👁

Window Previews

See live thumbnails of every window. Preview content before switching to make the right choice.

📝

Content Search

Search by what's visible in your windows using OCR. Find that terminal, document, or browser tab instantly.

⌨️

Keyboard First

Navigate entirely with your keyboard. Arrow keys to browse, Return to switch, Escape to dismiss.

⚡

Customizable Hotkey

Use the default ⌘⇧Space, or set your own. You can even replace ⌘Tab for seamless integration.

🚀

Launch at Login

Always ready when you need it. Winby starts automatically and lives in your menu bar.

How it Works

Simple, fast, powerful

Three steps to window switching nirvana.

1

Press Your Hotkey

Hit ⌘⇧Space (or your custom shortcut) to summon the window sidebar.

2

Type to Search

Start typing to filter windows. Use arrow keys to navigate the list.

3

Switch Instantly

Press Return to jump to your window. It's that simple.
